# ERP Pemerintahan Daerah Kabupaten Jember

Sistem Informasi Manajemen Data Pemerintahan Daerah Kabupaten Jember.

## Fitur

- Dashboard & Analitik Grafik
- Data Kependudukan (Warga, Keluarga, Dokumen)
- Bantuan Sosial (Program, Pengajuan, Penerima)
- Kesehatan (Rumah Sakit, Puskesmas, Rekam Medis, Vaksinasi, Stok Obat)
- SPK Klasifikasi Kemiskinan (Metode TOPSIS)
- Integrasi Data (SIAK, BPS, Sync Log)
- Pengaturan Sistem & Manajemen User

## Tech Stack

- PHP 7.4+ / MySQL
- Bootstrap 4.3.1
- Chart.js v2.8.0
- Material Design Icons
